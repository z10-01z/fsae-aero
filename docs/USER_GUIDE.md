# 使用说明

操作顺序：模型与轮胎 → 工况与物理 → 可选冷却 → 计算域与加密区 → 网格与近壁 → 计算与任务 → 结果与报告。

## 模型与轮胎

选择完整CATIA装配，检查所有引用、单位、装配变换及尺寸。软件通过独立副本处理模型。检查翼片、端板、杆件、底板、四轮、间隙和接地，不能只凭外观判断几何正确。

车身与轮胎合并时使用“拆出轮胎 · 保持车身整体”。先预览范围，再应用；其余车身保持整体，可撤销。检查区的定位、隔离及剖切只影响显示。

## 工况、域与网格

明确车头、向上方向、地面、四轮轴心/轴向和有效半径。速度、偏航、物性、参考量、稳态/非定常分别保存；显示颜色和镜头不改变计算输入。

计算域支持自动范围、手动范围和局部加密盒。表面曲率偏差与体积加密是不同控制；实际报告的STL偏差不等于解析CAD严格误差界限。目标单元数也不能替代几何保真及质量检查。

网格完成后查看实际导出的壁面、必需patch、基本/扩展质量、边界层覆盖与厚度。缺面、间隙失真、层铺不全应先解决，不能靠降低阈值标成通过。

## 任务与结果

在任务页核对输入和启动条件后执行。停止任务后等待后台实际结束；不要手动删除锁文件或认领其他程序的进程。续算需要兼容环境、输入和完整保存场。

结果页区分任务保存配置和当前编辑值。平均、瞬时、稳态迭代及统计窗口要一致；缺失数据表示未知。流线/矢量通常来自保存时刻的速度场，不冒充平均流线。

可以切换字段、截面、固定色标，导出CSV、图片、GIF和HTML。导出期间换场会停止并标为失败；仅 `manifest.json` 为 `completed` 的输出才是完成报告。缺报告的场数据不继承上一任务数值。

项目交接包可携带派生模型、配置及可选场；不携带场时只能查看报告。交接历史不含可直接恢复的Linux算例，不可据此续算。取消和重名不得覆盖已有项目。

## 工程判断

任务结束不等于收敛；残差、通量、力稳定性或非定常统计需同时检查。用有意义的网格加密、更大域以及适用时更小时间步/更长平均窗评估敏感性。不同几何结果不能当作同版精度对照。

冷却提供可配置空气侧模型。验证用假设参数不等于实车散热器数据，不能据此断言实车热性能。

## 反馈

记录构建号、最短操作步骤、预期/实际、是否重复，以及脱敏截图。不要公开包含凭证、真实车型或个人路径的反馈包。问题入口：[GitHub Issues](https://github.com/z10-01z/fsae-aero/issues)。
